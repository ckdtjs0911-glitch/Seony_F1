선수별 세션 랩타임 차트

긴 랩도 생략하지 않습니다. 빨간 점은 삭제 확인 랩입니다. 마우스를 올리면 랩 번호와 시간을 볼 수 있습니다.

지표 해석과 한계

  • 순위·완료 랩·포인트·격차는 session_result 원본입니다. API가 순위를 제공하지 않으면 임의 순위를 만들지 않습니다.
  • 퀄리파잉 Q1/Q2/Q3는 API duration 배열만 사용합니다. 빈 단계만으로 탈락을 단정하지 않으며, 미진출·미출전·기록 삭제의 구분은 공식 판정 대조가 필요합니다.
  • 관측 최속은 양수 랩 기록에서 race_control의 삭제 확인 랩을 제외한 최솟값입니다. 공식 유효 랩 판정과 다를 수 있습니다.
  • 중앙값 및 스틴트 중앙값은 1랩·피트 아웃·피트 진입·삭제 확인·누락 시간을 제외합니다. 연료량·트래픽·SC·VSC·트랙 변화는 보정하지 않아 순수 페이스나 롱런 우열을 단정하지 않습니다. 스틴트별 표본 수를 함께 표시합니다.
  • 피트 진입 수는 관측 랩의 시간 범위 안에서만 집계하며 타이어 교체 횟수나 실제 정차시간을 뜻하지 않습니다.
  • 세션별 공식 완료 랩과 관측 랩 기록 수는 별개입니다. 누락을 0초나 0랩으로 바꾸지 않습니다.
  • 스프린트 주말 등에서 프랙티스 2·3이 열리지 않으면 일정 없음으로 표시합니다. 이 보고서의 대상은 지정된 5개 세션이며 스프린트는 포함하지 않습니다.
  • 원본과 수집 시각은 각 세션 JSON 스냅샷에 보존합니다. 라이브 진행 중 공개 API가 차단되면 기존 스냅샷을 유지하고 다음 예약 실행에서 재조회합니다.
